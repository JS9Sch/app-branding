# Application branding

Public application information and privacy policies hosted on GitHub Pages.

Each application has a stable subfolder containing index.html and privacy.html. The root index links to applications.

## Applications

- Zo Drive Sync: zo-drive-sync/

## Publishing

GitHub Pages serves the main branch root. Use relative links so project-site paths work. Keep each policy specific to its application and consistent with the actual workflow. Never commit recordings, personal study materials, OAuth credentials, tokens or private runtime settings.
